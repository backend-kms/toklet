# Mac Note

단축키로 바로 열어 검색하고 복사하는 macOS 메뉴 막대 메모장.
SwiftUI + AppKit + Carbon으로 만들었으며 외부 패키지, 로그인, 서버가 없습니다.

## 로컬 실행

macOS 13 이상, Xcode 15 이상 또는 Swift 5.9 이상의 Command Line Tools가 필요합니다.
이 프로젝트 폴더를 맥으로 옮긴 후 터미널에서 실행하세요.

```bash
cd /실제/경로/mac-note
bash scripts/run.sh
```

개발 도구가 없다면 `xcode-select --install`로 설치하세요.
스크립트는 release 빌드 후 `.build/Mac Note.app`을 만들고 로컬 서명하여 실행합니다.
배포 인증서나 유료 Apple Developer 계정은 필요하지 않습니다.
터미널을 계속 열어둘 필요는 없습니다. 앱은 메뉴 막대에 남습니다.
소스 코드를 보려면 Xcode에서 `Package.swift`를 열면 됩니다.
수정 후 재실행할 때는 기존 앱을 메뉴 막대 우클릭 또는 설정의 ‘앱 종료’로 먼저 종료하세요.

## 사용

- 기본 전역 단축키: **Option + Space**. 다시 누르면 닫힙니다.
- 메뉴 막대의 `</>` 아이콘을 클릭해도 열고 닫을 수 있습니다. 우클릭 또는 Control + 클릭 → ‘앱 종료’로 종료합니다.
- 열면 검색창에 커서가 이동합니다. 제목과 본문 전체를 검색합니다.
- 검색창에서 Enter: 선택된 검색 결과의 본문 복사 후 닫기.
- 왼쪽은 검색·메모 목록, 오른쪽은 제목·본문 편집 영역입니다.
- 목록의 제목 클릭 또는 ‘제목 복사’: 제목 텍스트를 복사하고 ‘복사됨’을 표시합니다. 창은 유지하며 빈 제목은 복사하지 않습니다.
- 목록의 본문 미리보기나 여백 클릭: 메모 선택 후 제목·본문 편집. 입력할 때마다 로컬에 저장합니다.
- **Command + Enter** 또는 ‘본문 복사’: 본문 복사 후 원래 작업 앱으로 돌아갑니다.
- **Command + N**: 빈 메모를 만들고 제목 입력란에 커서를 둡니다. 제목에서 Enter를 누르면 본문으로 이동합니다. **Esc**: 창 닫기.
- 톱니바퀴: 단축키 조합 변경, 저장 위치 확인, 앱 종료.
- 단축키는 제공된 보조 키와 Space/N/M/J/K 조합 중 선택합니다.
- 단축키 등록 실패 시 다른 조합을 선택하세요. 일부 시스템 단축키와 충돌할 수 있습니다.
- 메모 삭제 전 확인합니다. 삭제 취소·휴지통 기능은 아직 없습니다.

## 저장

`~/Library/Application Support/MacNote/notes.json`

파일을 원자적으로 교체하여 저장하며, 기존 파일을 읽지 못하면 원본 보호를 위해 편집을 중지합니다.
복구하려면 앱 종료 후 파일을 별도 백업하여 내용을 점검하세요.
별도 백업·동기화·암호화는 없습니다. 암호나 토큰을 보관하는 용도로 사용하지 마세요.
단축키 설정은 macOS UserDefaults의 앱 설정에 저장합니다.

## 프로젝트 구조

- `Sources/MacNote/main.swift`: 메뉴 막대, 창, 클립보드, 포커스 복귀
- `Sources/MacNote/ContentView.swift`: 검색, 목록, 편집, 설정
- `Sources/MacNote/Notes.swift`: 메모 모델과 JSON 저장
- `Sources/MacNote/HotKey.swift`: 전역 단축키 등록
- `scripts/run.sh`: 빌드, 앱 번들 생성, 실행

## 검증 상태

macOS에서 release 빌드와 앱 번들 서명 검증을 통과했습니다.
샘플 메모로 기본 크기(900×600), 최소 크기(780×520), 빈 메모, 다크 모드 화면을 렌더링하여 제목 입력란과 본문이 겹치거나 잘리지 않는지 확인했습니다.
컴퓨터 제어 권한이 없어 실제 클릭과 클립보드 동작은 검증하지 못했습니다. 실행 후 아래를 확인해주세요.

1. 다른 앱에서 단축키로 열기, 검색창 포커스, Esc로 원래 앱 복귀.
2. 새 메모 추가 시 제목이 보이고 바로 입력되는지 확인, 제목에서 Enter로 본문 이동, 수정 → 앱 완전 종료 → 재실행 후 내용 유지.
3. 제목·본문 검색, 한국어 입력, 본문 미리보기 클릭으로 선택, 제목 클릭으로 제목 복사, 본문 복사 및 붙여넣기.
4. 단축키 변경 후 새 조합 작동, 기존 조합 해제, 앱 재실행 후 설정 유지.
5. 삭제 확인에서 취소·삭제, 메뉴 막대 `</>` 클릭으로 열고 닫기, 우클릭 또는 Control + 클릭 → ‘앱 종료’.
