# Toklet

개발 중 자주 쓰는 토큰, 테스트 값, 명령어를 프로젝트별로 적어두고 바로 복사하는 macOS 메뉴 막대 메모장.
SwiftUI + AppKit + Carbon으로 만들었으며 외부 패키지, 로그인, 서버가 없습니다.

## 만든 이유

개발하다 보면 API 테스트에 필요한 토큰, 요청에 넣을 값, 자주 쓰는 명령어처럼 반복해서 복사하고 붙여넣는 내용이 많습니다.
이런 값들을 바로 입력해두고, 필요할 때 빠르게 꺼내 쓰고 싶었습니다.

그런데 값 하나를 복사하려고 기존 메모 앱을 열고 메모를 찾은 뒤 다시 작업하던 앱으로 돌아오는 과정이 번거로웠습니다.
스티커 앱도 듀얼 모니터를 쓰는 환경에서는 사용하기가 불편했습니다.

Toklet은 이 불편함을 줄이려고 만들었습니다.
어떤 앱에서 작업하든 단축키로 바로 열고, 프로젝트별로 모아둔 값을 검색하고, 복사한 뒤 원래 작업으로 돌아갈 수 있도록 했습니다.
**개발 중 필요한 값을 쉽게 입력하고, 찾아서 복붙하는 흐름**에 집중합니다.

## 빠르게 사용하기

1. 왼쪽에서 프로젝트를 만들고 ‘새 메모’를 추가합니다. 제목에는 **개발용 Access Token**처럼 찾기 쉬운 이름을, 본문에는 복사해서 사용할 값을 넣습니다. **⌘V**로 붙여넣어도 되며 입력한 내용은 자동 저장됩니다.
2. API 테스트 도구나 에디터에서 작업하다가 **Option + Space**로 Toklet을 열고 메모를 검색합니다.
3. 검색창에서 **Enter** 또는 **⌘Enter**로 본문을 복사합니다. 원래 작업 앱으로 돌아오면 **⌘V**로 붙여넣습니다.

값이 바뀌면 카드의 본문이나 편집 아이콘을 눌러 수정하면 됩니다.
카드 제목을 클릭하면 **제목 텍스트**가 복사됩니다. 토큰처럼 본문에 적어둔 값은 카드의 복사 아이콘이나 ‘본문 복사’를 사용하세요.

## 로컬 실행

macOS 13 이상, Xcode 15 이상 또는 Swift 5.9 이상의 Command Line Tools가 필요합니다.
이 프로젝트 폴더를 맥으로 옮긴 후 터미널에서 실행하세요.

```bash
cd /실제/프로젝트/경로
bash scripts/run.sh
```

개발 도구가 없다면 `xcode-select --install`로 설치하세요.
스크립트는 release 빌드 후 `.build/Toklet.app`을 만들고 로컬 서명하여 실행합니다.
배포 인증서나 유료 Apple Developer 계정은 필요하지 않습니다.
터미널을 계속 열어둘 필요는 없습니다. 앱은 메뉴 막대에 남습니다.
소스 코드를 보려면 Xcode에서 `Package.swift`를 열면 됩니다.
수정 후 재실행할 때는 기존 앱을 메뉴 막대 우클릭 또는 설정의 ‘앱 종료’로 먼저 종료하세요.
터미널에서는 아래 순서로 종료하고 다시 빌드·실행할 수 있습니다.

```bash
pkill -x Toklet
bash scripts/run.sh
```

이름 변경 전 Mac Note가 실행 중이면 먼저 `pkill -x MacNote`로 종료하세요.
앱을 실행하지 않고 빌드만 하려면 `bash scripts/run.sh --build-only`를 사용하세요.

## 사용

- 기본 전역 단축키: **Option + Space**. 다시 누르면 닫힙니다.
- 메뉴 막대의 `</>` 아이콘을 클릭해도 열고 닫을 수 있습니다. 우클릭 또는 Control + 클릭 → ‘앱 종료’로 종료합니다.
- 왼쪽은 프로젝트 폴더 목록, 오른쪽은 선택한 폴더의 메모를 작은 카드로 보여줍니다. 한 줄에 4개씩 배치하며 카드 높이는 88pt입니다. 긴 제목은 마우스를 올리면 확인할 수 있습니다.
- ‘전체 메모’는 모든 프로젝트를, ‘기본’은 프로젝트에 배정하지 않은 메모를 보여줍니다.
- ‘프로젝트’ 옆 **+**로 프로젝트 추가. 프로젝트 이름 우클릭으로 이름 변경·삭제. 프로젝트를 삭제하면 메모는 ‘기본’으로 이동합니다.
- 열면 검색창에 커서가 이동합니다. 선택한 폴더 안에서 제목과 본문을 검색합니다.
- 검색창에서 Enter: 선택된 검색 결과(선택이 없으면 첫 결과)의 본문 복사 후 닫기.
- 카드의 제목 클릭: 제목 텍스트 복사 후 체크 표시. 편집 창의 ‘제목 복사’는 ‘복사됨’을 표시합니다. 창은 유지하며 빈 제목은 복사하지 않습니다.
- 카드의 본문 또는 편집 아이콘 클릭: 별도 편집 창에서 제목·본문 편집. 입력할 때마다 로컬에 저장합니다.
- 메모 편집 창의 ‘프로젝트’ 선택 또는 카드 우클릭 → ‘프로젝트로 이동’으로 메모를 옮깁니다.
- **Command + Enter** 또는 ‘본문 복사’: 본문 복사 후 원래 작업 앱으로 돌아갑니다.
- **Command + N**: 선택한 프로젝트에 빈 메모를 만들고 편집 창의 제목에 커서를 둡니다. ‘전체 메모’에서 만들면 ‘기본’에 저장합니다. 제목에서 Enter를 누르면 본문으로 이동합니다.
- 편집 창에서 **Esc** 또는 ‘완료’: 카드 목록으로 돌아갑니다. 카드 목록에서 **Esc**: 앱 창을 닫습니다.
- 제목·본문·검색·프로젝트 이름 입력란에서 **⌘C 복사, ⌘V 붙여넣기, ⌘X 잘라내기, ⌘A 전체 선택**을 사용할 수 있습니다. **⌘Z 실행 취소, ⌘⇧Z 다시 실행**도 기본 편집 메뉴에 연결합니다.
- 톱니바퀴: 단축키 조합 변경, 저장 위치 확인, 앱 종료.
- 단축키는 제공된 보조 키와 Space/N/M/J/K 조합 중 선택합니다.
- 단축키 등록 실패 시 다른 조합을 선택하세요. 일부 시스템 단축키와 충돌할 수 있습니다.
- 메모 삭제 전 확인합니다. 삭제 취소·휴지통 기능은 아직 없습니다.

## 저장

`~/Library/Application Support/Toklet/notes.json`

Toklet 저장 파일이 없으면 이전 Mac Note의 `~/Library/Application Support/MacNote/notes.json`을 읽습니다.
처음 저장할 때 Toklet 폴더에 기록하며 이전 파일은 보존합니다. 기존 전역 단축키 설정도 이어서 사용합니다.

파일을 원자적으로 교체하여 저장하며, 기존 파일을 읽지 못하면 원본 보호를 위해 편집을 중지합니다.
프로젝트와 메모를 하나의 JSON 문서로 저장합니다. 이전 메모 배열 형식도 읽으며, 기존 메모는 ‘기본’으로 표시합니다.
이전 형식에서 처음 저장할 때 원본을 같은 폴더의 `notes.json.legacy-backup`에 보존한 뒤 새 형식으로 저장합니다. 같은 이름의 백업이 있으면 UUID를 붙인 새 백업을 만듭니다.
복구하려면 앱 종료 후 파일을 별도 백업하여 내용을 점검하세요.
메모와 형식 변환 시 생성한 백업은 암호화하지 않은 로컬 JSON 파일로 저장합니다. 자동 동기화와 정기 백업은 지원하지 않습니다.
단축키 설정은 macOS UserDefaults의 앱 설정에 저장합니다.

## 프로젝트 구조

- `Sources/Toklet/main.swift`: 메뉴 막대, 창, 클립보드, 포커스 복귀
- `Sources/Toklet/ContentView.swift`: 프로젝트 폴더, 메모 카드, 검색, 설정
- `Sources/Toklet/NoteEditorView.swift`: 메모 편집과 프로젝트 이름 입력
- `Sources/Toklet/AppMenu.swift`: 입력란의 기본 편집 단축키
- `Sources/Toklet/Notes.swift`: 프로젝트·메모 모델과 JSON 저장, 기존 형식 읽기
- `Sources/Toklet/HotKey.swift`: 전역 단축키 등록
- `scripts/run.sh`: 빌드, 앱 번들 생성, 실행

## 검증 상태

macOS에서 release 빌드와 앱 번들 서명 검증을 통과했습니다.
저장소 테스트 10개로 기존 파일·백업 보존, 프로젝트 추가·이름 변경·이동·삭제·재로드, 잘못된 입력과 저장 실패 시 상태 보존, Mac Note 저장 파일에서 이어 쓰기를 확인합니다.
단축키 설정 호환 테스트 2개와 편집 메뉴 테스트 1개를 포함해 총 13개 테스트를 `swift test`로 실행합니다.
편집 메뉴 테스트로 기본 단축키가 편집 대상에 전달되는지 확인합니다. 별도 AppKit 입력창에서도 실제 클립보드를 이용해 복사·붙여넣기·전체 선택·잘라내기 명령을 검증했습니다.
샘플 메모로 기본 크기(900×600), 최소 크기(780×520), 다크 모드, 빈 카드 목록과 편집 창을 렌더링하여 배치와 제목 입력란을 확인했습니다.
실행 중인 앱의 실제 클릭·키 입력 흐름은 별도의 수동 확인 항목입니다. 실행 후 아래를 확인해주세요.

1. 다른 앱에서 단축키로 열기, 검색창 포커스, Esc로 원래 앱 복귀.
2. 새 메모 추가 시 제목이 보이고 바로 입력되는지 확인, 제목에서 Enter로 본문 이동, 수정 → 앱 완전 종료 → 재실행 후 내용 유지.
3. 프로젝트 추가·선택, 카드 열기, 메모를 다른 프로젝트로 이동, 프로젝트 이름 변경, 프로젝트 삭제 후 ‘기본’에 메모가 남는지 확인.
4. 폴더별 제목·본문 검색, 한국어 입력, 카드 제목 클릭으로 제목 복사, 본문 복사 및 붙여넣기.
5. 단축키 변경 후 새 조합 작동, 기존 조합 해제, 앱 재실행 후 설정 유지.
6. 삭제 확인에서 취소·삭제, 메뉴 막대 `</>` 클릭으로 열고 닫기, 우클릭 또는 Control + 클릭 → ‘앱 종료’.
